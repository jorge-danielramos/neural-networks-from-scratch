# Neural Networks from Scratch

Coursework implementation in Python and NumPy for IFT6135. Includes dense layers, sigmoid/ReLU/tanh activations, MLP models, mean squared and absolute error losses, and stochastic gradient descent with explicit backpropagation.

## Setup

```sh
python -m pip install -r requirements.txt
python train.py --help
```
